# Avito watcher bot — Render

Telegram-бот: следит за выдачей Авито и присылает новые объявления с подсказкой, сколько предложить.

Токен НЕ хранится в репозитории — он задаётся в Render в переменной `BOT_TOKEN`.

Переменные:
- `SEARCHES` — поиски, по одному на строку: `ссылка | название` (на Render диск стирается при рестарте, поэтому поиски задаются здесь; /add тоже работает, но до перезапуска)
- `DEFAULT_EXCLUDE` — слова-исключения через запятую
- `CHECK_INTERVAL` — секунд между проверками
- `PROXY` — российский прокси для Авито, если он блокирует IP Render (`http://user:pass@host:port`)
