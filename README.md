# Avito watcher bot — Render

Telegram-бот: следит за выдачей Авито и присылает новые объявления с подсказкой, сколько предложить.

Как пользоваться:
- Чтобы добавить поиск, пришли боту ссылку с Авито, а название можно написать с новой строки (или через пробел). Без названия возьмётся текст поиска из ссылки.
- `/list` — поиски с номерами 1, 2, 3… (после удаления номера сдвигаются, дыр нет)
- `/name 1 Vita Сочи` — переименовать, `/del 1` — удалить
- `/price 1 5000 15000`, `/exclude 1 чехол, игра`, `/stats 1`
- `/check` — немедленная проверка своих поисков: число прочитанных объявлений,
  отправок, исключений фильтрами и конкретные ошибки. При первом успешном чтении
  бот запоминает текущую выдачу без рассылки старых объявлений.

Токен НЕ хранится в репозитории — он задаётся в Render в переменной `BOT_TOKEN`.

Переменные:
- `SEARCHES` — поиски, по одному на строку: `ссылка | название` (на Render диск стирается при рестарте, поэтому поиски задаются здесь; /add тоже работает, но до перезапуска)
- `DEFAULT_EXCLUDE` — слова-исключения через запятую
- `CHECK_INTERVAL` — секунд между проверками
- `PROXY` — российский прокси для Авито, если он блокирует IP Render (`http://user:pass@host:port`)
- `PROXY_FALLBACK` — по умолчанию `1`: если соединение через прокси не установилось,
  бот пробует прямой доступ и повторяет попытку через прокси через 5 минут.
  Поставьте `0`, если запросы должны идти только через заданный прокси.
  Ошибка `CONNECT tunnel failed, response 403` означает отказ прокси на этапе
  соединения, а не отсутствие новых объявлений. Проверьте срок оплаты, разрешённые
  IP и данные доступа у провайдера. Пароль прокси и токен бота нельзя присылать в чат
  или добавлять в GitHub.

Неотправленные объявления сохраняются в очереди SQLite и повторяются даже при
недоступности Авито. При недоступности фото бот отправляет текст с целой HTML-разметкой.
Пауза после блокировки Авито не мешает повторным отправкам в Telegram.

Ограничение Render Free: при остановке, перезапуске и новой публикации локальная
SQLite-база и очередь пропадают. `SEARCHES` восстанавливает ссылки, но не историю
объявлений и не настройки, введённые командами. Самопинг не даёт гарантии непрерывной
работы. Для постоянной истории нужен внешний постоянный накопитель данных либо
постоянный диск с `DB_PATH` на нём (диск недоступен на Free).
Документация: https://render.com/docs/free

Проверка исправлений без настоящих токенов и запросов к Telegram/Авито:

```bash
python -m unittest discover -s tests -v
```
